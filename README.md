# Skyward weather app

Search current weather by city or your device location. The dashboard includes
temperature conversion, humidity, wind, pressure, visibility, sunrise and
sunset, quick city picks, and recent searches for the current session. Weather
and place search are provided by Open-Meteo and do not require an API key.

## Run locally

1. Install dependencies and start the app:

   ```sh
   npm install
   npm start
   ```

## Tests and production build

```sh
npm test -- --watchAll=false
npm run build
```
